# Week 6 — Views and Component Architecture

This branch implements the Week 6 interface-binding lab for the Node/Express school supply store.

## Included

- Shared UI styles and reusable navigation/component helpers in public/css and public/js.
- Static Dashboard, Products, Suppliers, Customers, and Sales screens.
- List/index, detail, create, and edit views for each CRUD area.
- Empty, loading, and error state examples on list/dashboard screens.
- Placeholder/sample data only; no real backend data binding yet.
- Component and screen mapping documentation.
- Required Week 6 AI prompt log.

## Run

npm install
npm start

Open http://localhost:3000/ui/ in a browser.

Week 7 will connect these views to the existing backend controllers and handle real loading/error behavior.
