# Main Branch Protection — Required Final Configuration

## Required GitHub settings
- Require a pull request before merging.
- Require at least 1 approving review.
- Restrict direct pushes to main.
- Keep develop separate from finalization work.

## Evidence status
This file documents the required configuration. The repository cannot truthfully claim protection was enabled and tested until a repository administrator performs that action in GitHub and records the actual result.

## Recommended test
Create a small test branch and pull request, verify direct-push behavior is blocked, and verify merging is gated by the required approval. Record the actual result in the final evidence record.

## Why this matters
Branch protection is process evidence. Documentation is not a substitute for the actual GitHub setting.
