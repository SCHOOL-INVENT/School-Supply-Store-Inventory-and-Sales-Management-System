## Deliberately unclaimed human evidence

The repository does not fabricate these items:

- GitHub Project board creation and actual assignments.
- Main branch protection configuration and test.
- Teammate review and approval submissions.
- Live browser CRUD and failure-path results.
- Classroom rehearsal and presentation delivery.
- Team retrospective answers.
- Individual unassisted oral defense.

## Final submission principle

The strongest submission is evidence-backed. Repository files document what was built and how it should be verified; real human or live-environment events must be recorded only after they occur.
