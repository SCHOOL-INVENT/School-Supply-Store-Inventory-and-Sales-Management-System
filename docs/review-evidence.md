# Pull Request Review Evidence Guide

The course requires reviewed pull requests, not only merged pull requests.

## What counts as review evidence
- Reviewer username
- Review action: APPROVE, COMMENT, or REQUEST_CHANGES
- Review timestamp
- Pull request number

## Final verification
Do not create synthetic approvals or claim that a teammate reviewed a pull request unless the review is actually present in GitHub.

Before final submission, the team should verify review history for the required PRs and record only genuine approvals and feedback.
