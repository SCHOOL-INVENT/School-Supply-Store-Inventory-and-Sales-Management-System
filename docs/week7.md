# Week 7 — Form Submission & Asynchronous Operations

## Included

- Fetch-based Create and Update form submission.
- No full-page reload on form submit.
- Loading state with disabled submit button.
- Success handling for controller responses.
- Visible 422 field-level error handling.
- General network/server error handling.
- Dynamic Products, Suppliers, Customers, and Sales lists loaded from the backend.
- Edit links pass the real record ID and Update forms pre-fill from GET endpoints.
- Product/Sales selects load available records from the backend.
- End-to-end test checklist in `docs/binding-tests.md`.
- Required AI prompt log in `docs/ai-notes/week-07.md`.

Real persistence is performed by the existing Phase 2 controllers/data layer. Week 7 connects the Week 6 UI to those endpoints.
