# Week 1 Problem Statement

## Project
School Supply Store Inventory and Sales Management System

## Problem

The school supply store needs a simple way to keep inventory records organized because supplies, stock quantities, suppliers, customers, and sales can become difficult to track consistently using manual records. The proposed system will centralize these records and allow authorized users to create, read, update, and delete supply-related information while monitoring stock levels and recording sales transactions.

## Scope for the course

The project is intentionally small and CRUD-shaped. The first version will manage four related record types:

1. Products / school supplies
2. Suppliers
3. Customers
4. Sales / transactions

The system will not attempt to become a marketplace, social network, or large enterprise inventory platform.

## One-sentence description

A school supply inventory and sales system that helps a small school-supply store manage products, suppliers, customers, stock levels, and sales records in one place.
