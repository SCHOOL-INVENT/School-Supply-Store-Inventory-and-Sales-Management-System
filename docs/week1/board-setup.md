# Week 1 Task Board Setup

The handout requires a board with these columns:

**Backlog → To Do → In Progress → In Review → Done**

Create these four Week 1 tickets and assign an owner to each:

| Ticket | Suggested title | Required evidence |
|---|---|---|
| W1-01 | Team roster and roles | Names and starting roles |
| W1-02 | Project problem statement | Problem statement + 3–4 record types |
| W1-03 | GitHub repository setup | Repo URL + branch-protection evidence |
| W1-04 | GitHub Project board setup | Board URL + four owned tickets |

A ticket is not complete for the course requirement until an owner is assigned. Move completed tickets to **Done**.

## Board checklist

- [ ] Create GitHub Project from the repository's Projects tab.
- [ ] Create columns: Backlog, To Do, In Progress, In Review, Done.
- [ ] Add W1-01 through W1-04.
- [ ] Assign one team member to every ticket.
- [ ] Move completed work to Done.
- [ ] Keep the board as the source of truth for Week 1 contribution evidence.
